## 实测 bug 修复（同日，用户实测反馈）
- 用户开 app 实测：配置窗无 min/max/close 顶栏、网页空白、app 打开显示成表格。逐条校验 development-plan 与重述需求 → **完全一致，需求无偏差**，全是实现 bug。
- **P1-A 网页空白**：rust-embed key 带 `assets/` 前缀，而 axum 路由 `/assets/{*path}` 的 `{*path}` 只捕获剥前缀片段，`DistAssets::get()` 查不到 → 全 404 白屏。修法：`serve_asset(&format!("assets/{path}"))` 补前缀。定位手法：临时 example `embed_check` 列嵌入 key + handler 打日志对比，随即删除 example。
- **P1-B 配置窗顶栏消失**：`.titlebar` 无固定高度且无 `flex-shrink:0`，被 `.config-body` 的 `flex:1` 在 flex column 布局里压没了。修法：`height:44px; flex-shrink:0`；补最大化按钮（toggleMaximize）凑齐三件套；`capabilities/default.json` 显式加 `core:window:allow-minimize/toggle-maximize/close/hide/show/set-focus/unminimize`（`core:default` 只含各模块只读 default 集，变更操作需显式授权，否则前端调用静默失败）。
- 验证：重启 serve.exe 后 4 assets + index.html + config.html 全 200，config-*.js 含 titlebar/toggleMaximize/最大化；cargo 7 集成 + vitest 6 + vue-tsc 全绿。
- **关键经验**：rust-embed 的 key = 相对 folder 的完整路径（含子目录前缀），axum `{*path}` 捕获的是剥前缀片段，拼接再查。
