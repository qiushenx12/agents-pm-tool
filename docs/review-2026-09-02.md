## 实测问题追加（用户实测反馈）

用户打开 app 实测发现 2 个规划外 bug，均已修复并回归全绿：

### P1-A 网页空白（assets 全部 404）✅ 已修
- **根因**：`server/static_site.rs::asset` 的 axum 路由是 `/assets/{*path}`，`{*path}` 通配符**只捕获 `/assets/` 之后的部分**（如 `index-D38gak0I.js`）；但 rust-embed 的 key 是带 `assets/` 前缀的完整路径（`assets/index-D38gak0I.js`）。两者不匹配 → `DistAssets::get()` 返回 None → 404 → index.html 引用的 JS/CSS 全挂 → 白屏。
- **定位手法**：临时 example `embed_check` 列出嵌入 key 清单（都带 `assets/` 前缀）+ 在 handler 里打调试日志确认收到的是无前缀片段，两者一对即现形。
- **修复**：`serve_asset(&format!("assets/{path}"))` 补回前缀。
- **验证**：重启服务后 4 个 assets + index.html + config.html 全部 200；index.js 含「任务表/新建任务/任务描述/当前状态」UI 字符串。
- **教训**：rust-embed 的 key = 磁盘相对 folder 的完整路径；axum `{*path}` 捕获的是剥前缀片段，拼回去再查。

### P1-B 配置窗顶栏（最小化/最大化/关闭）消失 ✅ 已修
- **根因**：`ConfigApp.vue` 的 `.titlebar` 没有固定高度也没 `flex-shrink: 0`，而父容器 `.config-app` 是 `display:flex; flex-direction:column; height:100%`，`.config-body` 的 `flex:1` 把 height 为 auto 的 titlebar 完全压缩掉（内容 overflow）→ 整条顶栏不可见。
- **修复**：
  - `.titlebar` 加 `height: 44px; flex-shrink: 0;`（并移除多余的 `-webkit-app-region` 实验，`data-tauri-drag-region` 已够）。
  - 补「最大化/还原」按钮（`appWindow.toggleMaximize()`），凑齐 最小化/最大化/关闭 三件套。
  - `capabilities/default.json` 显式加 `core:window:allow-minimize / toggle-maximize / close / hide / show / set-focus / unminimize`（`core:default` 只含各模块只读 default 集，不含这些变更操作；不写会导致前端调用静默失败）。
- **验证**：vite build 后新 hash 的 `config-*.js` 里含 `titlebar / toggleMaximize / 最大化` 字符串；cargo test 7 集成 + vitest 6 + vue-tsc 全绿。

## P2 — 应修

### P2-1 删除任务不清磁盘附件（孤儿文件）✅ 已修
- **位置**：`src-tauri/src/db/tasks.rs::remove`
- **现象**：删任务靠 `ON DELETE CASCADE` 清 attachments 表行，但 `data/attachments/` 下的实际文件未删除，长期累积孤儿文件。
- **规划依据**：§4.1 attachments 落盘在 data/ 下；删除任务（仅网页端）应连同附件一起清理。
- **修法**：`remove` 改为先查出该任务全部 `stored_path`，事务内删行（级联），提交后逐个 `std::fs::remove_file`（失败仅告警不回滚）。
- **实际修复**：`tasks::remove` 返回被级联删除的附件路径清单（DB 层不碰文件系统，保持分层），`api_web.rs::delete_task` 拿到清单后逐个删磁盘文件，失败打 eprintln 告警不回滚。新增集成测试 `delete_task_removes_attachment_files`（真实 multipart 上传 → 断言落盘 → 删任务 → 断言文件消失）。

### P3-1 附件白名单拆成两个数组，易漂移 ✅ 已修

- **现象**：`ALLOWED_EXTENSIONS`(14) + `EXTRA_EXTENSIONS`(["xlsx"]) 两段拼接，注释自辩"共 15 个"。

### P3-2 Agent describe 接受空描述，与 create 校验不对称 ✅ 已修
- **位置**：`src-tauri/src/server/api_agent.rs::patch_description`
- **现象**：`body.description.unwrap_or_default()` 无 trim/非空校验，Agent 可传 `""` 清空自己任务的描述；而 create 要求描述 trim 后非空。
- **实际修复**：与 create 对齐——trim 后为空则 422（"描述不能为空（--description）"）；集成测试补 3 个用例（`""`、`"   "`、缺字段）。

### P3-3 save_settings 提示语与实际行为不符 ✅ 已修
- **位置**：`src-tauri/src/lib.rs::save_settings` + `src/config-app/ConfigApp.vue::save`
- **现象**：仅改 `autostart`/`close_behavior` 时服务不会重启，但提示固定为"已保存，服务已按新配置运行"。
- **实际修复**：Rust 命令返回 `SaveSettingsResult { settings, restarted, port }`；前端按 `restarted` 区分提示（"已保存，服务已重启并运行在 …" / "已保存（端口未变，服务无需重启）"）；端口标签文案改为"修改后保存将重启服务"。
