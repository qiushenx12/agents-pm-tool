# 界面改版实施与验收记录

日期：2026-09-07

## 已实施

- 工作区骨架：可折叠项目导航、快捷筛选、分层页头、表格工具栏、筛选条件标签、记录统计和连接状态。
- 统一明暗主题、SVG 图标、按钮、标签、输入、定位菜单、对话框和提示组件。
- 任务描述主列、冻结表头和主列、长文本截断、三档行高、列宽拖拽、列显隐、本地布局偏好。
- 单元格选中、双击或 Enter 编辑、方向键和 Tab 移动、Ctrl+Enter 保存、Esc 取消、Alt+Enter 打开详情。
- 筛选、搜索、排序及布局设置共用浮层；保留筛选 URL 和关键词防抖。
- 详情宽度调整、属性编辑、描述编辑、前后记录导航、附件上传队列及媒体预览。
- 新建任务继承项目上下文；附件部分失败后只重试失败文件，保留已创建的任务。
- 项目新增、重命名、颜色设置、顺序调整、删除确认及引用保护错误展示。
- 桌面配置窗按服务状态、常用设置、连接设置和 Agent 接入分组，使用共享组件。
- 列表请求失效控制、同一任务写入串行化、SSE 刷新合并、失败保留草稿、外部修改提示。
- 详情独立于当前列表筛选读取更新；任务被外部删除时提示并保留最后内容。
- 前端每页 100 条，支持页码跳转，可以访问原先 2000 条截断之后的记录。

开发预览的 esbuild/Safari 14 目标冲突已修复：依赖预构建与项目已有的浏览器构建目标保持一致。新增 `PM_API_TARGET` 开发代理覆盖，便于使用独立验收服务。
